# Figma Junior Tutorial Plan

A progressive 4-week learning path for junior designers new to Figma.

---

## Week 1 — Interface & Navigation

| Day | Topic |
|-----|-------|
| Day 1 | ✅ Figma overview — canvas, layers panel, properties panel, toolbar |
| Day 2 | ✅ Frames vs Groups — when to use each, auto-layout basics |
| Day 3 | Shapes, text, and basic vector editing (pen tool) |
| Day 4 | Fill, stroke, effects (shadows, blur), color styles |
| Day 5 | Mini project: recreate a simple app screen from scratch |

---

## Week 2 — Components & Design Systems

| Day | Topic |
|-----|-------|
| Day 1 | Creating components, instances, and overrides |
| Day 2 | Variants — states (hover, active, disabled), boolean properties |
| Day 3 | Styles — color, text, and effect tokens |
| Day 4 | Local library vs shared library concepts |
| Day 5 | Mini project: build a button component with 4 variants |

---

## Week 3 — Auto Layout & Responsive Design

| Day | Topic |
|-----|-------|
| Day 1 | Auto layout fundamentals — padding, gap, direction |
| Day 2 | Hug vs Fill vs Fixed sizing |
| Day 3 | Constraints and responsive frames |
| Day 4 | Building responsive cards and nav bars |
| Day 5 | Mini project: design a mobile card list that adapts to content |

---

## Week 4 — Prototyping & Handoff

| Day | Topic |
|-----|-------|
| Day 1 | Prototype connections — triggers, transitions, overlays |
| Day 2 | Smart animate and micro-interactions |
| Day 3 | Inspect panel — reading specs as a developer would |
| Day 4 | Dev Mode basics, export settings (PNG, SVG, CSS) |
| Day 5 | Final project: design + prototype a 3-screen mobile app flow |

---

## Bonus Topics (after core plan)

- **Plugins:** Unsplash, Iconify, Phosphor Icons
- **FigJam:** Wireframing and brainstorming flows
- **Code Connect:** Linking components to a codebase
- **Variables:** Design tokens for light/dark mode

---

## Recommended Resources

- [Figma official Learn](https://help.figma.com/hc/en-us/categories/360002051613) — free official docs
- [Figma YouTube channel](https://www.youtube.com/@Figma) — video walkthroughs
- Community files: search "UI Kit" or "Design System" in Figma Community for practice references

---

> Each week builds on the last. Mini projects ensure hands-on practice rather than passive watching.
